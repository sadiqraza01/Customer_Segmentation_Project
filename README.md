# 🧩 Customer Segmentation Project

This project applies **clustering techniques** to segment customers based on purchasing behavior, demographics, and engagement.

## 🚀 Project Overview
- **Goal**: Identify customer groups to improve targeted marketing.
- **Dataset**: Marketing Campaign Dataset (839 rows, 18 features).
- **Techniques Used**: KMeans, DBSCAN, Agglomerative Clustering, Gaussian Mixture Model.
- **Evaluation**: Silhouette Score, Davies-Bouldin Index, Calinski-Harabasz Index.

## 📊 Results
- Best Model: **KMeans (k=3)**
- Segments Identified:
  1. High-Income Big Spenders
  2. Budget-Conscious Families
  3. Young Shoppers
  4. Inactive Customers

## 🛠️ Tech Stack
- Python, Pandas, Numpy, Scikit-learn, Matplotlib, Seaborn
